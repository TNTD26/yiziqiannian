# 4、创意来源

汉字是中华文明延续数千年的重要载体，而甲骨文作为目前已知较为成熟的古文字体系之一，记录了先民对自然、社会与生活的观察。传统汉字文化具有深厚的历史价值，但其传播形式往往以静态文字、图片和资料介绍为主，年轻群体较难形成直观而深入的体验。因此，本作品希望利用 AIGC 与数字交互技术，让汉字从"被阅读的文字"转变为"可以被探索、生成和体验的数字生命"。通过人工智能重新诠释甲骨文的形态与文化意象，在传统文化与现代数字艺术之间建立连接，使古老文字以更加符合当代年轻人审美和交互习惯的方式重新进入大众视野。

---

## 三个具体的出发点

**1）古文字的传播形态停留在"被观看"**

博物馆里的甲骨拓片、教材上的字形表，本质上都是静态图像。观者看到的是结果，而不是过程 —— 没有人见过"日"这个字是怎样从一轮带点的太阳，一步步被简化成方方正正的"日"。本作品把这个"被压缩掉的三千年"重新展开：识别 → 还原 → 演化 → 再创作，让观者亲手完成一次文字考古。

**2）AI 不该只是生成一张好看的图**

许多文化类 AI 作品停留在"输入关键词，输出一张古风插画"。本作品希望 AI 承担更本质的角色 —— **认字**。为此实现了一套可在浏览器内离线运行的视觉识别管线（灰度 → Otsu 自适应二值化 → 连通域裁剪 → 96×96 归一化 → 三层卷积分类器输出 119 类后验概率，置信度经温度缩放校准；并以 16×16 网格密度投影 + 骨架拓扑 + 几何特征作为兜底通道），全过程对用户可见可调，而不是一个黑箱 API 调用。同时保留接入任意 OpenAI 兼容多模态大模型的通道，形成"CNN 主通道 + 本地兜底 + 云端增强"的三路架构。

**3）字形必须是真的**

创作初期曾用手写矢量字形，结果甲骨文与金文画得几乎一样、隶书因系统缺字体被回退成楷书 —— 形态失真意味着文化失真。本作品最终改用开源古文字字形数据集（etymology-svg）中的真实字形 SVG，逐字导入并适配渲染管线。119 个字、跨 5 个书体的每一个笔画都来自真实字源（楷书因使用标准文字，采用系统字库渲染）。

## 想达成的体验

让一个不了解甲骨文的人，在三分钟内完成一次完整的心智闭环：

> 看到一片看不懂的古老刻痕 → AI 告诉它可能是"鹿" → 屏幕展开它三千年的变形过程 → 它变成一幅可以带走的艺术品 → 最后成为一团在屏幕上呼吸旋转的光。

从"这个字我不认识"，到"这个字好像活过来了"。
