# 使用说明 · 评审导览

## 启动软件

解压后双击根目录的 `一字千年.exe`，软件会自动启动本地服务并以独立应用窗口打开界面，无地址栏、无启动状态文字；关闭窗口即结束本地服务与进程。备用兼容入口为 `START.html` / `打开作品.html`（用 Chrome / Edge 直接打开）。

## 三分钟快速体验路线

> 建议评委按以下顺序操作，可以在最短时间内看到作品的全部关键能力。

| 步骤 | 位置 | 操作 | 会看到什么 |
|---|---|---|---|
| 1 | AI 识别馆 | 点右侧"或从字形库取样"中的任意字（如 **鹿**），再点「开始 AI 识别」 | 左侧逐步输出预处理管线：二值图、16×16 网格投影、骨架拓扑数据（端点/交叉/墨量/空腔数/对称度），右侧给出 AI 推测结果、置信度与候选排序 |
| 2 | AI 识别馆 | 上传一张自己的甲骨文字形图片（PNG/JPG，或直接 Ctrl+V 粘贴） | 同一条管线作用于外部真实图片，验证不是"预设答案" |
| 3 | 识别结果区 | 点「查看演化轨迹」 | 该字的甲骨文 → 金文 → 小篆 → 隶书 → 楷书自动逐帧播放 |
| 4 | AI 识别馆 | 点「在实验室创作这幅字」 | 自动带入识别结果进入创作区 |
| 5 | AI 造字实验室 | 切换"视觉语言"（龟甲骨卜辞 / 青铜铭文 / 水墨 / 数字粒子），点「生成」 | Canvas 程序化重绘艺术作品，带印章与落款编号 |
| 6 | AI 造字实验室 | 点「＋ 收藏到展厅」「⤓ 导出作品 PNG」 | 作品保存到本地画廊；导出 900×900 PNG 到下载目录 |
| 7 | 3D 数字生命 | 点「孕育 3D 生命」 | 字形被还原成 12000 个粒子的三维点云，可拖拽旋转、滚轮缩放，自动经历"混沌星尘 → 聚合生长 → 呼吸 → 五体演化"，支持导出视图 |
| 8 | 数字展厅 | 回到展厅查看收藏的作品 | 支持大图查看、下载、删除 |

## 各功能细节

### AI 识别馆
- **两种取样方式**：上传本地图片 / 直接从 119 字字形库取样（取样图会先在 Canvas 上渲染成图片，叠加做旧底纹、噪声点与随机磨损后进入识别，走完全相同的处理流程，非理想输入）。
- **可视化中间件**：右上角三块小画布实时显示灰度二值图、16×16 网格密度投影、以及拓扑统计（含空腔数），让"AI 怎么看字"这件事是可见的。
- **三路识别通道**：
  - 卷积字形分类器（主通道）—— 离线训练的 119 类 CNN，权重随包携带，浏览器内纯 JavaScript 推理；界面上的置信度就是它输出的后验概率，经温度校准，可解释、可核对。
  - 本地特征引擎（兜底）—— 密度投影 + 骨架拓扑 + 几何统计比对，CNN 权重未加载时自动接管。
  - 云端多模态模型（可选）—— 在右上角「⚙ AI 设置」中填入任意 OpenAI 兼容服务的 BaseURL / 模型名 / API Key 即可启用（内置 DeepSeek、通义千问、智谱 GLM、硅基流动、本地 Ollama 等预设）。云端失败时自动回落本地，并在日志中标明实际使用的通道。
- **结果处理**：识别结果给出首选项与候选排序，右侧同步展示该字的现代字形、拼音、造字法释义与例句。

### 关于云端模型的填写
DeepSeek 目前只有一个模型支持图片输入：`deepseek-v4-flash-vision-exp`；填其他模型名会提示"不支持图片输入"。若不想配置，跳过即可 —— **所有功能不依赖云端**。

### AI 造字实验室
- 输入任一汉字（限单字），选择"取形书体"（甲骨文 / 金文 / 小篆 / 隶书 / 楷书）与"视觉语言"。
- 若输入的字不在内置字库中，页面会提示并使用替代字形，避免空白。
- 导出同时提供 2400×2400 高清版与 1200×1700 竖版展览海报。

### 3D 数字生命
- 控件：鼠标拖拽旋转、滚轮缩放；「⏸ 暂停巡演」「⇢ 立即演化」「⤓ 导出视图 PNG」三个按钮分别控制自动巡演、手动切换到下一书体、导出当前画面。

## 常见问题

**Q：打开后是空白/样式错乱？**
A：请先确认已从压缩包**完整解压**到本地文件夹，再双击根目录的 `一字千年.exe`；软件会自动启动本地服务并以独立应用窗口打开。若改用兼容入口，请用 Chrome 或 Edge 打开 `START.html`（或 `打开作品.html`）。

**Q：3D 展区黑屏？**
A：该展区依赖 WebGL2。请在浏览器设置中开启"使用硬件加速"（chrome://settings/system），或换用桌面端 Chrome/Edge。其余功能不受影响。

**Q：收藏的作品下次打开还在吗？**
A：在。桌面版把浏览器用户目录固定在 `%LOCALAPPDATA%\YiziqianNian\UserProfile`，收藏的作品缩略图保存在 localStorage 中，关闭软件再打开仍然存在；手动清理该目录的浏览器数据才会一并清除。

**Q：断网还能演示吗？**
A：能。字形库、识别引擎、艺术生成、字体全部随包本地化，离线可完整运行，仅"云端大模型识别"一项需要联网。
