# 5、运行环境

Windows 10/11 操作系统。作品为桌面应用软件，双击根目录的 `一字千年.exe` 即可运行：程序自动在本机启动专用服务，并以独立应用窗口打开界面（无地址栏、无标签栏、无状态栏）。界面由 Microsoft Edge / Google Chrome 的 Chromium 内核按系统 DPI 原生渲染，文字与图形清晰。作品采用 HTML、CSS、JavaScript 及 WebGL 等技术开发，部分 AIGC 内容通过人工智能生成工具制作。

---

## 最低与推荐配置

| 项目 | 最低 | 推荐 |
|---|---|---|
| 操作系统 | Windows 10（64 位） | Windows 11 |
| 浏览器内核 | Microsoft Edge 90+ 或 Chrome 90+（Windows 10/11 自带 Edge） | Edge / Chrome 最新版 |
| 分辨率 | 1366×768 | 1920×1080 及以上 |
| 显卡 | 支持 WebGL2 的集成显卡 | 独立显卡（3D 展区粒子更流畅） |
| 网络 | **不需要联网** | 联网可启用云端大模型识别增强 |
| 依赖安装 | **无需安装任何软件、无需 Node / Python / 服务器环境** | —— |

## 三种运行方式

**方式一：桌面应用（推荐）**

解压后双击根目录的 `一字千年.exe`。程序会：

1. 在 `127.0.0.1` 的空闲端口启动一个仅供本软件使用的本地服务；
2. 以独立应用窗口打开软件界面，窗口内不显示任何地址或启动状态文字；
3. 关闭窗口时，通过页面通知在短暂确认后停止服务并结束进程；刷新页面不会误关软件，窗口异常终止时由心跳超时兜底退出。

浏览器用户数据保存在 `%LOCALAPPDATA%\YiziqianNian\UserProfile`，因此「数字展厅」中收藏的作品在下次启动时仍然存在。

**方式二：兼容入口（评审备用）**

直接双击 `START.html`（或中文别名 `打开作品.html`），用 Chrome / Edge 打开即可完整运行。此方式下 Service Worker 不会注册，其余功能不受影响。

**方式三：桌面快捷方式**

双击 `创建桌面快捷方式.bat`，会在桌面生成带作品图标的「一字千年」快捷方式，之后从桌面双击进入。

> 高级用法：如需自行以本地服务器方式提供页面，可在目录内执行 `python -m http.server 8080`，再访问 `http://127.0.0.1:8080/START.html`。桌面版已自动完成这一步，通常无需手动操作。

## 兼容性说明

- **已做离线处理**：Noto Serif SC、Outfit 两个开源字体随包本地化，无 CDN 依赖。
- **无外部 API 依赖**：神经网络识别在本地浏览器内完成，不调用任何在线接口。
- **云端模型为可选增强**：仅在用户主动于「AI 设置」中填写自己的 API Key 时才发起外部请求；不填则功能完全不受影响。
- **移动端**：页面已做响应式适配，低于 900px 宽度时导航转为可横向滑动的标签条；建议评委仍使用桌面端体验以获得完整的 3D 效果。
- **已知限制**：3D 展区依赖 WebGL2，个别老旧浏览器或禁用硬件加速时可能无法显示点云；此时其余七个展区不受影响。
