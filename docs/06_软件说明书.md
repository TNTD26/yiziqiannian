## 二、软件开发目的与适用领域

本软件面向中华古文字文化的数字化展示与科普教育，将甲骨文字形的识别、汉字字形的历时演化、AIGC 数字艺术创作与三维可视化整合为一个可离线运行的桌面应用。用户上传或选取一片甲骨文字形，软件在本地完成图像预处理与卷积分类，给出候选汉字及可校准的置信度，并据此还原字源、释义、五体演化，进一步生成可导出的数字艺术作品与可旋转的三维「数字生命体」。

适用领域：文化遗产数字化展示、博物馆与课堂科普、人工智能教学演示、数字媒体艺术创作、AIGC 竞赛作品。

## 三、软件主要功能

软件界面由顶部导航串联八个功能模块，各模块均可离线独立运行。

| 序号 | 模块 | 功能说明 |
|---|---|---|
| ① | 序章 | 动态甲骨粒子背景与作品导语，提供两条体验入口 |
| ② | 汉字探索 | 119 个汉字的字源、释义、古诗文与甲骨文／金文／小篆／隶书／楷书字形检索 |
| ③ | 文字演化 | 五体字形对照与自动播放，展示同一汉字自甲骨文至楷书的形态流变 |
| ④ | AI 甲骨文识别馆 | 上传图片或从字库取样 → 图像预处理可视化 → 卷积分类 → 候选汉字排序与置信度展示 |
| ⑤ | AI 造字实验室 | 以识别结果为种子，用 4 种视觉语言程序化生成数字艺术作品，支持高清图与海报导出 |
| ⑥ | 3D 数字生命 | 将字形点云化为可旋转、可缩放、按「混沌→聚合→存活→演化」四相位变化的三维生命体 |
| ⑦ | 数字展厅 | 收藏、回放与管理本机生成的作品，缩略图持久化保存在浏览器本地存储 |
| ⑧ | 关于 | 技术路径、数据出处、软件版本与权利声明 |

辅助功能：AI 引擎设置（可接入任意 OpenAI 兼容的多模态视觉模型作为可选增强）、作品大图查看与下载、Toast 提示、键盘与响应式适配。

## 四、操作流程

### 4.1 启动

1. 将压缩包完整解压到任意本地目录（勿在压缩包内直接运行）。
2. 双击根目录的 `一字千年.exe`。
3. 程序自动在本机回环地址的空闲端口启动专用服务，并以独立应用窗口打开软件界面。窗口无地址栏、无标签栏、无状态栏，不显示任何启动状态文字。
4. 首次启动约需 1–3 秒（程序自解压），随后进入「序章」首页。

### 4.2 核心识别流程

1. 点击顶部导航「AI 识别」进入识别馆。
2. 选择「上传图片」，或点击字库中的字形直接取样（取样会自动叠加做旧底纹、噪点、微旋转与磨损以模拟拓片）。
3. 界面展示灰度、二值化、包围盒裁剪、96×96 归一化等预处理阶段的可视化结果。
4. 卷积分类器输出 119 类的后验概率，界面按置信度降序展示前若干候选汉字。
5. 选中结果后可跳转「文字演化」查看五体流变，或进入「AI 造字实验室」生成作品并收藏到「数字展厅」。

### 4.3 其他模块

- 「汉字探索」：在搜索框输入汉字或点击字形库条目，查看字源与释义；字形库区域支持滚轮滚动。
- 「文字演化」：点击播放按钮自动依次呈现五种书体。
- 「AI 造字实验室」：选择视觉语言，点击生成；可导出高清 PNG 或海报。
- 「3D 数字生命」：拖拽旋转、滚轮缩放，点击「演化」切换相位。
- 「数字展厅」：点击卡片查看大图、下载或移除。

### 4.4 退出

直接关闭软件窗口即可。页面在 `pagehide` 时通过 `sendBeacon` 通知启动器，启动器经短暂观察确认页面不再存活后，停止本地服务、释放端口并结束进程；期间若检测到新心跳（例如按 F5 刷新页面）则取消退出，因此刷新不会误关软件。若窗口异常终止，则由心跳超时机制兜底退出。无需在任务管理器中手动结束进程，退出后不残留后台服务。数字展厅中的收藏保存在持久化用户目录中，下次启动仍然存在。

### 4.5 兼容入口

双击 `START.html`（或中文别名 `打开作品.html`）可用 Chrome / Edge 直接打开界面，功能完整，仅不注册 Service Worker 与桌面窗口生命周期管理。

## 五、技术特点

1. **离线卷积字形分类器**：三层卷积网络（8/16/24 通道）＋全连接层，119 类输出，softmax 后经温度缩放校准（T = 0.94）。置信度即模型后验概率，非人工拟合分数。权重以 float32 base64 随包携带，浏览器内用纯 JavaScript 推理，无需联网、GPU 或任何运行时依赖。
2. **三路识别通道**：CNN 主通道、本地特征引擎兜底（网格密度投影、骨架拓扑、几何统计）、云端多模态模型可选增强；任一通道失败自动降级，保证演示不中断。
3. **训练与推理严格对齐**：Python 训练侧逐行复刻前端 `Vision.extract()` 预处理管线，输出一致的 96×96 二值图；共 23,503 张三路混合样本（字库规范字形、程序化形变、HUST-OBC 真实拓片）。
4. **纯前端 AIGC 生成**：Canvas 2D 多套视觉语言程序化绘制，字形矢量库随包本地化，无 CDN、无后端、无数据上传。
5. **WebGL2 三维数字生命**：Three.js 驱动的点云系统，四相位动画，支持交互旋转与字形／书体切换。
6. **桌面应用容器**：启动器仅负责本地服务与独立应用窗口，不介入业务逻辑；采用进程互斥防止重复启动，采用页面心跳＋`sendBeacon` 实现可靠的关闭检测；界面由 Chromium 按系统 DPI 原生渲染，避免宿主层位图缩放导致的文字发虚。
7. **完全离线**：开源字体（Noto Serif SC、Outfit）与全部脚本、图像随包携带，Service Worker 提供二次访问缓存。
