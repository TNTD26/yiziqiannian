# 技术文档

## 一、总体架构

```
一字千年.exe                （桌面应用主程序，见第五节）
└─ source/launcher.py      本地静态服务 + 独立应用窗口 + 关闭检测

START.html  （界面入口）
├─ assets/css/style.css         全部样式，含本地化开源字体 @font-face
├─ assets/js/glyphs-real.js     真实古文字字形数据（119 字 × 4 书体，来自 etymology-svg）
├─ assets/js/glyphs.js          字形库封装：119 字 × 5 书体、造字法、释义、出处
├─ assets/js/vision.js          图像预处理 + 本地特征引擎（兜底通道）
├─ assets/js/obicnn.js          卷积字形分类器：float32 权重 + 纯 JS 推理器（主通道）
├─ assets/js/ai.js              三路识别桥接：CNN / 本地特征 / 云端 + 错误诊断
├─ assets/js/art.js             Canvas 程序化数字艺术生成（4 种视觉语言）
├─ assets/js/life3d.js          Three.js 3D 数字生命（点云 + 着色器 + 生命周期）
├─ assets/js/three.min.js       Three.js r160（本地，无 CDN 依赖）
└─ assets/js/script.js          页面逻辑与交互编排
```

全部为原生 HTML + CSS + JavaScript，**无构建工具、无框架、无外部服务端依赖**；桌面版另附一个 Python 启动器（已打包为 exe），仅在本机回环地址提供静态文件，不承担任何业务逻辑。

## 二、识别管线：卷积分类器 + 本地特征引擎

识别采用**三路通道**，全部在浏览器内完成：主通道是离线训练的卷积字形分类器，本地特征引擎兜底，云端多模态模型为可选增强。

### 2.1 图像预处理（vision.js）

1. **灰度化**：Canvas `getImageData` → 加权灰度。
2. **Otsu 自适应阈值二值化**：按类间方差最大自动求阈值；自动判别极性（拓片多为黑底白字，字库渲染为白底黑字）。
3. **去噪**：填补笔画内部磨损小孔 → 3×3 中值滤波 → 剔除面积过小的碎斑 → 剔除贴边的框状杂墨。
4. **包围盒裁剪**：求墨迹包围盒，保持长宽比等比缩放并居中到 96×96。
5. **两路输出**：`normRaw`（未经骨架化的 96×96 二值图）供 CNN 使用；`skel`（去斜 → 骨架化 → 膨胀）供特征引擎使用。

### 2.2 卷积字形分类器（obicnn.js，主通道）

`normRaw` 经 2×2 平均池化为 48×48 单通道张量，送入：

> Conv 3×3×8 → ReLU → MaxPool2 → Conv 3×3×16 → ReLU → MaxPool2 → Conv 3×3×24 → ReLU → MaxPool2 → Flatten(864) → FC(128) → ReLU → FC(119) → Softmax(T=0.94)

- 参数量约 13 万，float32 权重无损内嵌（511 KB），单次推理约 1.5M 次乘加；纯 JavaScript 实现，无 ONNX / TensorFlow.js / WASM 等任何运行时依赖，断网、无 GPU 均可运行。
- **置信度即 softmax 后验概率**，经温度缩放校准（T 在与被测域同分布的验证集上，以「ECE + 置信度—准确率偏差」为目标网格搜索得出），不是人工拟合的分段线性分数。

### 2.3 训练集构成

| 来源 | 样本数 | 作用 |
|---|---|---|
| 项目字库 119 字 × 5 书体规范字形 | 595 | 域内基准，覆盖评委「取样」演示 |
| 上述字形的程序化形变（旋转 / 非均匀拉伸 / 弹性 / 断笔 / 磨损 / 斑点） | 15,470 | 扩充类内多样性 |
| HUST-OBC 已破译集真实拓片 | 7,438 | 域外真实数据，提升泛化 |

共 23,503 张，按字分层划分训练 / 验证 / 测试；真实拓片在训练中过采样以对抗域偏移。训练在离线环境完成，包内只携带训练得到的权重，不含原始数据集图像。

### 2.4 实测结果

| 测试集 | top-1 | top-3 | 平均置信度 |
|---|---|---|---|
| 规范字形 119 字 × 5 书体（595 条，浏览器内端到端回归） | **99.50%** | — | 95.4% |
| 真实出土拓片（850 张，独立留出、跨数据集零适配） | **79.76%** | **88.24%** | 79.68% |

其中甲骨文书体 119/119 全部命中；复刻评委「取样」完整链路（做旧底纹 + 噪点 + 微旋转 + 随机磨损）实测 **119/119 = 100%**，平均置信度 94.9%。真实拓片测试的期望校准误差 **ECE = 0.0280**，平均置信度 79.68% 与实际准确率 79.76% 基本吻合。真实拓片的难度来自同一个字存在大量异体写法、残损与拓印噪声，且测试数据与训练数据来源不同；两类结果分别报告，避免用单一数字掩盖域间差异。

### 2.5 兜底与增强通道

`skel` 走特征引擎：16×16 网格密度投影（软化后 512 维）+ 骨架拓扑（端点、交叉点、空腔数）+ 几何统计，与 119 字 × 5 书体逐一加权比对并跨书体投票。当 CNN 权重未加载或推理异常时自动接管；用户也可在「AI 设置」中接入任意 OpenAI 兼容的多模态视觉大模型作为可选增强，云端失败同样回落本地。

## 三、三路识别通道（ai.js）

```
用户图片
   │
   ├─ 主通道（始终执行）─→ CNN 后验概率 → 首选字 + Top-N 候选
   │
   ├─ 兜底通道（CNN 不可用时）─→ 特征比对候选列表
   │
   └─ 云端通道（可选，需用户自备 Key）
         ├─ 成功且结果在字库内  → 采用云端结果
         ├─ 成功但结果为库外字  → 云+本地融合（取本地首位，保留云端理由）
         └─ 失败（401/404/429/不支持图片/无 JSON/网络错误）→ 静默回落本地
```

错误诊断：对 HTTP 状态码与响应体做语义解析，区分 Key 无效、模型不支持图片、模型不存在、限流、接口路径错误、跨域失败等多种情况，并在界面上给出可执行的修正建议；同时按服务商给出针对性提示（如 DeepSeek 必须使用 `-vision-exp` 后缀的视觉模型）。

## 四、3D 数字生命（life3d.js）

1. **栅格化**：把目标字形离屏渲染到 128×128 画布，取 alpha 通道。
2. **距离变换**：对字形内外的距离场做腐蚀，估算笔画厚度 —— 用来给点云加"体积感"，避免平面浮雕的纸片效果。
3. **深度加权采样**：按距离场权重随机采样 12000 个点，构成三维点云。
4. **生命周期着色器**：自定义 GLSL，控制点的大小、透明度与颜色随时间演化，依次表现"混沌星尘 → 聚合生长 → 呼吸 → 书体演化"。
5. **交互**：轨道拖拽、滚轮缩放、暂停/立即演化、导出视图 PNG。

> 粒子尺寸采用物理正确公式 `uPixScale = bufferHeight / (2·tan(fov/2))` 并限制在 1–26px，使帧率与分辨率解耦，在无独显的办公本上亦可流畅运行。

## 五、桌面应用容器（source/launcher.py）

桌面版把网页界面封装为可独立运行的 Windows 应用。启动器只提供运行容器，不改动、不替代任何业务逻辑；网页源文件本身不含桌面相关代码。

| 环节 | 实现 |
|---|---|
| 启动 | 在 `127.0.0.1` 的**空闲端口**启动 `ThreadingHTTPServer`，静态资源目录指向 exe 所在目录 |
| 界面 | 以 Edge / Chrome 的 `--app=<url>` 打开独立应用窗口，配合专用 `--user-data-dir`；无地址栏、无标签栏、无状态栏。启动器不设置任何窗口隐藏标志，保证窗口正常显示 |
| 清晰渲染 | 窗口由 Chromium 按系统 DPI 原生渲染，不经过任何 WinForms / WebView2 宿主层的位图缩放；**不加** `--disable-gpu`，保证 WebGL2 可用 |
| 后台节流 | `--disable-background-timer-throttling` 等参数保证窗口最小化时心跳与 3D 动画仍正常推进 |
| 无状态文字 | 启动器无任何可见 UI（PyInstaller `--noconsole`），界面中不存在启动状态 Label 或地址输入框 |
| 单实例 | Windows 命名互斥体防止重复双击产生多个服务与窗口 |
| 关闭 | 页面在 `pagehide` 时用 `sendBeacon` 通知 `/__shutdown`；启动器进入 2.5 秒观察窗口，期间无新心跳才停止服务、释放端口并结束进程，避免刷新被误判为关闭 |
| 兜底 | 页面每 2 秒发送 `/__heartbeat`；心跳可否决关闭请求（刷新场景），窗口异常终止时由心跳超时兜底退出 |
| 数据持久 | 浏览器用户目录固定在 `%LOCALAPPDATA%\YiziqianNian\UserProfile`，数字展厅收藏跨次启动保留 |

界面页的桌面桥接脚本由服务端在响应 `START.html` 时**运行时注入**（仅心跳与关闭通知），因此直接双击 HTML 用浏览器打开时零副作用。启动器以 `/` 与 `/index.html` 的 302 回落兼容 Service Worker 的导航缓存。

## 七、工程质量措施

- **离线优先**：无任何 CDN 依赖，字体本地化，开箱即用。
- **PWA**：`manifest.webmanifest` + `sw.js`，HTML 与 JS/CSS 走 network-first、失败回落缓存，兼顾"改完代码立刻生效"与"现场断网可用"。
- **存储保护**：展厅作品保存为 480×480 JPEG 缩略图（约 40KB/张），配额不足时逐条回退写入，避免 localStorage 溢出。
- **可访问性**：上传区支持键盘操作与粘贴（Ctrl+V）；Esc 关闭弹窗；尊重系统 `prefers-reduced-motion` 设置。
- **质量验证**：595 条规范字形端到端回归 592/595 正确；CNN 权重导回 PyTorch 与浏览器 JS 推理逐样本比对，最大概率差 5×10⁻⁵；云端链路对成功、鉴权失败、模型不支持图片、返回非 JSON、库外字五种情形均正确回落本地；全站控制台无报错。

## 八、后续可扩展方向

- 扩充字库：当前 119 字 × 5 书体，可继续按同一数据管线扩展到常用 500 字（上游数据集本就含 500 字）。
- 识别增强：引入更大字表（HUST-OBC 已破译集含 1,588 类）与更深的骨干网络，并针对真实拓片做域自适应。
- 多字识别：由单字扩展到整片卜辞的切字与逐字识别。
- 教学场景：配套"字形临摹打分"与课程任务包。
