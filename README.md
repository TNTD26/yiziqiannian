# 一字千年 · AI 甲骨文数字生命馆

> 上传一片甲骨，让 AI 找回它失落三千年的名字 —— 再把它重新养成一个会呼吸的数字生命。

一次融合 **AIGC、数字艺术与交互技术** 的中华汉字文化数字创意作品。以甲骨文为切入点，通过 AI 图像识别、字形演化、程序化艺术生成与三维点云，把古文字从静态的历史符号转化为可探索、可生成、可体验的"数字生命"。

桌面应用软件 V1.0 · Windows 10/11

---

## 三大核心能力

| 能力 | 说明 |
|---|---|
| **AI 识别** | 内置离线卷积字形分类器（3 层 CNN，119 类），输入预处理后的 48×48 二值字形，输出经温度校准的 softmax 后验概率。纯 JavaScript 推理，无需联网、无需 GPU |
| **文字演化** | 甲骨文 → 金文 → 小篆 → 隶书 → 楷书 五体对照与自动播放，119 字字源、释义与古诗文 |
| **数字生成** | 4 种视觉语言程序化生成数字艺术，可导出高清图与海报；字形点云化为可旋转、四相位演化的三维生命体 |

## 八个功能模块

1. **序章** — 动态甲骨背景
2. **汉字探索** — 119 字字源 · 释义 · 古诗文
3. **文字演化** — 五体对照与自动播放
4. **AI 识别馆** — 上传或取样 → 预处理可视化 → AI 推测 → 候选排序
5. **AI 造字实验室** — 4 种视觉语言生成，导出高清图与海报
6. **3D 数字生命** — 字形点云化为三维生命体
7. **数字展厅** — 收藏与回放生成的作品
8. **关于** — 技术路径、字形来源与免责声明

## 实测指标（独立留出集）

| 测试集 | 结果 |
|---|---|
| 评委取样链路（119 字，含做旧底纹 / 噪点 / 随机磨损） | 119/119 = **100%**，平均置信度 94.9% |
| 规范字形 119 字 × 5 书体（595 条） | 592/595 = **99.50%**，甲骨文 119/119 |
| 真实出土拓片 850 张（跨数据集零适配） | top-1 **79.76%** / top-3 88.24%，ECE 0.0280 |

训练集共 23,503 张：项目字库规范字形 + 程序化形变样本 + HUST-OBC 已破译集真实拓片。训练离线完成，权重随包携带（`assets/js/obicnn.js`，约 687 KB）。

## 快速开始

**方式一 · 桌面应用（推荐）** — 双击 `一字千年.exe`
以独立应用窗口打开，无地址栏、无标签栏、无状态栏；关闭窗口即自动结束本地服务与进程。

**方式二 · 浏览器** — 双击 `START.html`（中文别名：`打开作品.html`），用 Chrome 或 Edge 打开。

**方式三 · 桌面快捷方式** — 双击 `创建桌面快捷方式.bat`。

- Windows 10/11 自带 Edge 即可，无需安装任何软件
- 无需联网：字体、字形库、AI 引擎全部随包携带
- 首次启动需 1~3 秒自解压，属正常现象

## 技术栈

HTML / CSS / JavaScript · WebGL2（Three.js r160）· 纯 JS 卷积推理 · Canvas 程序化生成 · Service Worker 离线缓存 · Python 桌面启动器（标准库 HTTP 服务 + Chromium app 模式）

可自行接入任意 OpenAI 兼容的多模态视觉大模型（右上角「AI 设置」）。CNN 权重未加载或云端失败时，自动回落到本地特征引擎，不影响演示。
