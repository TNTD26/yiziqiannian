一字千年 · AI 甲骨文数字生命馆   |   桌面应用软件 V1.0
================================================================

【怎么运行】
  方式一（推荐，桌面应用）：双击「一字千年.exe」
        软件以独立应用窗口打开，无地址栏、无标签栏、无状态栏，
        不显示任何启动状态文字；界面按系统 DPI 原生渲染，文字清晰。
        关闭窗口即自动结束本地服务与进程，退出后无残留后台程序。
  方式二（兼容入口）：双击 START.html
        （中文别名：打开作品.html，两者内容完全一致）
        用 Chrome 或 Edge 打开即可，功能同样完整。
  方式三：双击「创建桌面快捷方式.bat」，会在桌面生成一个
        带作品图标的快捷方式，之后从桌面双击进入。

  · 无需安装任何软件（Windows 10/11 自带 Edge 即可）
  · 无需联网（字体、字形库、AI 引擎全部随包携带）
  · 请勿在压缩包内直接打开，请先解压
  · 重复双击不会启动多个实例
  · 首次启动需 1~3 秒自解压，属正常现象

【识别能力】
  内置离线卷积字形分类器（3 层 CNN，119 类）。输入为预处理后的
  48×48 二值字形，输出经温度校准的 softmax 后验概率 —— 置信度就是
  模型给出的概率本身，可解释、可校准，不是人工拟合的分数。

  训练集共 23,503 张：项目字库 119 字 × 5 书体的规范字形、由这些字形
  程序化生成的形变样本、以及 HUST-OBC 已破译集的真实拓片。训练在离线
  环境完成，权重随包携带（assets/js/obicnn.js，约 687 KB），浏览器内用
  纯 JavaScript 推理，无需联网、无需 GPU、无需任何运行时依赖。

  实测（独立留出集）：
    · 评委取样链路（119 字，含做旧底纹 / 噪点 / 随机磨损）
      119/119 = 100%，平均置信度 94.9%
    · 规范字形 119 字 × 5 书体（595 条）  592/595 正确 = 99.50%
      其中甲骨文书体 119/119，平均置信度 95.4%
    · 真实出土拓片 850 张（跨数据集零适配） top-1 79.76% / top-3 88.24%
      平均置信度 79.68%，期望校准误差 ECE 0.0280
  真实拓片因异体写法多、残损与拓印噪声重，与规范字形分列报告。

  另可自行接入任意 OpenAI 兼容的多模态视觉大模型（右上角「AI 设置」）；
  CNN 权重未加载或云端失败时，自动回落到本地特征引擎，不影响演示。
